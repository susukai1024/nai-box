📦 Cloudflare R2 配置步骤
① 创建 R2 存储桶
  1. 登录 dash.cloudflare.com
  2. 左侧菜单点「R2 对象存储」→「创建存储桶」
  3. 桶名填 nai-gallery，区域选「自动」，点「创建」
② 获取 API 凭证
  1. 在 R2 页面右上角点「管理 R2 API 令牌」
  2. 点「创建 API 令牌」→ 权限选「对象读与写」
  3. 指定存储桶选刚才创建的 nai-gallery
  4. 点「创建 API 令牌」，复制以下三项：
    • 账户 ID（页面右侧可找到）→ 填入「Account ID」
    • 访问密钥 ID → 填入「Access Key ID」
    • 机密访问密钥（只显示一次，务必立刻复制）→ 填入「Secret Access Key」
③ 允许公开访问
  1. 进入 nai-gallery 存储桶 → 「设置」→「公开访问」
  2. 点「允许访问」或绑定一个自定义域名
  3. 图片 URL 格式将变为 https://pub-xxx.r2.dev/img/xxx.png
③-B 配置 CORS（必须做，否则 App 无法读写）
  1. 还是在 nai-gallery 存储桶 → 「设置」→ 找到「CORS 策略」
  2. 点「添加 CORS 策略」，把下面这段复制进去然后保存：
[{
  "AllowedOrigins": ["*"],
  "AllowedMethods": ["GET","PUT","DELETE","HEAD"],
  "AllowedHeaders": ["*"],
  "ExposeHeaders": ["ETag"],
  "MaxAgeSeconds": 3600
}]
不做这步的话保存卡片时会报跨域错误，图片传不上去
④ 填入下方表单并保存
保存后即可使用「🚀 一键上传」把本地数据同步到 R2 云端。
⚠️ 机密访问密钥只显示一次，记得保存在安全的地方。如果丢失需要重新创建 API 令牌。 ☀️不会的可以登录CLOUDFLARE后右上角AI，让它帮你操作

在 R2 存储桶「设置→公开访问」开启后获取，格式如 pub-abc123.r2.dev
